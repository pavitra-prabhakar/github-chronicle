# 📈 Growth, 2012 to 2017

> With its first outside funding, GitHub grew from a startup into the default home of open source. It also became a toolmaker: Atom and its runtime Electron reshaped desktop software, and Git LFS extended Git to large files.

| When | Milestone |
|---|---|
| July 9, 2012 | **First outside investment** |
| February 2014 | **Atom, a hackable text editor** |
| April 2015 | **Atom Shell becomes Electron** |
| April 8, 2015 | **Git Large File Storage** |

## First outside investment

**July 9, 2012** · _company_

After four bootstrapped, profitable years, GitHub takes its first outside investment: $100 million led by Andreessen Horowitz.

Source: <https://github.blog/news-insights/investing-in-github/>

## Atom, a hackable text editor

**February 2014** · _product_

GitHub introduces Atom, a 'hackable text editor for the 21st century', and open sources it a few months later.

Source: <https://en.wikipedia.org/wiki/Atom_(text_editor)>

## Atom Shell becomes Electron

**April 2015** · _open-source_

The framework built for Atom is renamed Electron. It goes on to power many desktop apps, including Visual Studio Code, Slack and Discord.

Source: <https://en.wikipedia.org/wiki/Electron_(software_framework)>

## Git Large File Storage

**April 8, 2015** · _open-source_

GitHub announces Git LFS, an open source Git extension for versioning large files such as audio, video and datasets.

Source: <https://github.blog/news-insights/announcing-git-large-file-storage-lfs/>
