# 🤝 The Microsoft era, 2018 to 2020

> Microsoft's acquisition worried some developers, but the years that followed made GitHub dramatically more generous and capable: free private repositories, GitHub Actions, Sponsors, npm, Codespaces, Discussions and the Arctic Code Vault.

| When | Milestone |
|---|---|

| October 2018 | **GitHub Actions is announced** |
| October 26, 2018 | **Acquisition closes, Nat Friedman becomes CEO** |

| May 23, 2019 | **GitHub Sponsors** |

| March 16, 2020 | **npm joins GitHub** |
| April 14, 2020 | **GitHub is free for teams** |
| May 6, 2020 | **Codespaces and Discussions** |

## Microsoft agrees to acquire GitHub

**June 4, 2018** · _company_

Microsoft announces an agreement to acquire GitHub for $7.5 billion in stock, with GitHub continuing to operate independently.

Source: <https://news.microsoft.com/2018/06/04/microsoft-to-acquire-github-for-7-5-billion/>

## GitHub Actions is announced

**October 2018** · _product_

At GitHub Universe 2018, GitHub unveils Actions in beta: automation workflows that live right next to your code.

Source: <https://github.blog/news-insights/product-news/universe-day-one/>

## Acquisition closes, Nat Friedman becomes CEO

**October 26, 2018** · _company_

Microsoft completes the acquisition and Nat Friedman becomes GitHub's CEO.

Source: <https://blogs.microsoft.com/blog/2018/10/26/microsoft-completes-github-acquisition/>

## Free private repositories

**January 7, 2019** · _product_

GitHub Free gains unlimited private repositories (initially with up to three collaborators), removing one of the biggest reasons to pay for a personal account.

Source: <https://github.blog/news-insights/product-news/new-year-new-github/>

## GitHub Sponsors

**May 23, 2019** · _community_

Announced at GitHub Satellite in Berlin, Sponsors lets the community fund the open source developers they depend on.

Source: <https://github.blog/news-insights/company-news/building-an-interconnected-community-together/>

## GitHub Actions and Packages leave beta

**November 13, 2019** · _product_

At Universe 2019, GitHub Actions (with built-in CI/CD) and GitHub Packages become generally available, free for public repositories. The GitHub Archive Program is announced the same day.

Source: <https://github.blog/news-insights/product-news/universe-day-one/>

## npm joins GitHub

**March 16, 2020** · _company_

GitHub announces it is acquiring npm, the company behind the JavaScript package registry.

Source: <https://github.blog/news-insights/company-news/npm-is-joining-github/>

## GitHub is free for teams

**April 14, 2020** · _product_

Private repositories with unlimited collaborators become free for all organizations, including teams.

Source: <https://github.blog/news-insights/product-news/github-is-now-free-for-teams/>

## Codespaces and Discussions

**May 6, 2020** · _product_

At GitHub's first virtual Satellite, GitHub announces Codespaces (cloud dev environments powered by VS Code), Discussions, and code and secret scanning.

Source: <https://github.blog/news-insights/company-news/new-from-satellite-2020-github-codespaces-github-discussions-securing-code-in-private-repositories-and-more/>

## The Arctic Code Vault

**July 2020** · _community_

A snapshot of public repositories taken on February 2, 2020 is deposited in the Arctic World Archive in Svalbard, designed to last 1,000 years.

Source: <https://archiveprogram.github.com/arctic-vault/>

## GitHub CLI 1.0

**September 17, 2020** · _product_

The official `gh` command line tool reaches 1.0, bringing pull requests, issues and more to the terminal.

Source: <https://github.blog/news-insights/product-news/github-cli-1-0-is-now-available/>

## main becomes the default branch name

**October 1, 2020** · _product_

New repositories on GitHub use `main` as the default branch name instead of `master`.

Source: <https://github.blog/changelog/2020-10-01-the-default-branch-for-newly-created-repositories-is-now-main/>
