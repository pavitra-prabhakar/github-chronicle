# 🌱 Origins, 2007 to 2011

> GitHub began as a weekend side project by Chris Wanstrath and Tom Preston-Werner, soon joined by PJ Hyett and Scott Chacon. Git was powerful but hard to share; GitHub made it social. The company stayed bootstrapped and profitable, growing on paid private repositories while open source lived there for free.

## The first commit to GitHub

**October 19, 2007** · _company_

Chris Wanstrath makes the first commit to the GitHub codebase, a side project started with Tom Preston-Werner after a Ruby meetup in San Francisco. PJ Hyett and Scott Chacon soon join as co-founders.

Source: <https://tom.preston-werner.com/2008/10/18/how-i-turned-down-300k>

## GitHub launches publicly

**April 10, 2008** · _company_

After a private beta, GitHub officially launches as a hosted Git service built around social coding: profiles, forks, and a network of collaborators.

Source: <https://en.wikipedia.org/wiki/Timeline_of_GitHub>

## Gist is born

**July 21, 2008** · _product_

GitHub launches Gist, a way to share snippets and small files where every gist is itself a Git repository.

Source: <https://en.wikipedia.org/wiki/Timeline_of_GitHub>

## GitHub Pages

**December 18, 2008** · _product_

GitHub Pages lets anyone publish a static website straight from a repository, later powered by Jekyll, the static site generator created by Tom Preston-Werner.

Source: <https://en.wikipedia.org/wiki/Timeline_of_GitHub>

## One million repositories

**July 24, 2010** · _growth_

GitHub passes one million hosted repositories, roughly two and a half years after launch.

Source: <https://en.wikipedia.org/wiki/Timeline_of_GitHub>
