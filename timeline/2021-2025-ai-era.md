## GitHub Copilot technical preview

**June 29, 2021** · _ai_

GitHub introduces Copilot, an AI pair programmer built with OpenAI, as a technical preview in Visual Studio Code.

Source: <https://github.blog/news-insights/product-news/introducing-github-copilot-ai-pair-programmer/>

## Thomas Dohmke becomes CEO

**November 15, 2021** · _company_

Thomas Dohmke succeeds Nat Friedman as GitHub's CEO.

Source: <https://en.wikipedia.org/wiki/GitHub>

## Copilot is generally available

**June 21, 2022** · _ai_

GitHub Copilot becomes generally available to individual developers, free for verified students and maintainers of popular open source projects.

Source: <https://github.blog/news-insights/product-news/github-copilot-is-generally-available-to-all-developers/>

## Atom is sunset

**December 15, 2022** · _product_

As announced in June 2022, GitHub archives Atom and its repositories. Its biggest legacy, Electron, lives on.

Source: <https://github.blog/news-insights/product-news/sunsetting-atom/>

## 100 million developers

**January 25, 2023** · _growth_

GitHub announces that more than 100 million developers use the platform.

Source: <https://github.blog/news-insights/company-news/100-million-developers-and-counting/>

## 2FA becomes mandatory for contributors

**March 13, 2023** · _security_

GitHub begins requiring two-factor authentication for developers who contribute code on GitHub.com, rolling out in groups through 2023.

Source: <https://github.blog/news-insights/product-news/raising-the-bar-for-software-security-github-2fa-begins-march-13/>

## Copilot Chat is generally available

**December 29, 2023** · _ai_

Copilot Chat, a conversational assistant in VS Code and Visual Studio, becomes generally available in all Copilot plans.

Source: <https://github.blog/news-insights/product-news/github-copilot-chat-now-generally-available-for-organizations-and-individuals/>

## Copilot Workspace preview

**April 29, 2024** · _ai_

GitHub previews Copilot Workspace, a task-centric environment that goes from an issue to a plan to code.

Source: <https://github.blog/news-insights/product-news/github-copilot-workspace/>

## Copilot goes multi-model

**October 29, 2024** · _ai_

At Universe 2024, GitHub announces model choice in Copilot, including models from Anthropic, Google and OpenAI.

Source: <https://github.blog/news-insights/product-news/bringing-developer-choice-to-copilot/>

## Copilot Free and 150M developers

**December 18, 2024** · _ai_

GitHub launches a free tier of Copilot in VS Code and shares that it has passed 150 million developers.

Source: <https://github.blog/news-insights/product-news/github-copilot-in-vscode-free/>

## Copilot coding agent

**May 19, 2025** · _ai_

At Microsoft Build, GitHub announces the Copilot coding agent: assign an issue to Copilot and it works asynchronously in an Actions-powered environment, then opens a pull request for review.

Source: <https://github.blog/changelog/2025-05-19-github-copilot-coding-agent-in-public-preview/>

## GitHub moves into Microsoft CoreAI

**August 11, 2025** · _company_

Thomas Dohmke announces he will step down as CEO to found a new startup; GitHub's leadership continues as part of Microsoft's CoreAI organization.

Source: <https://github.blog/news-insights/company-news/goodbye-github/>

## Agent HQ

**October 28, 2025** · _ai_

At Universe 2025, GitHub announces Agent HQ, a mission control for assigning and tracking coding agents from multiple providers directly on GitHub.

Source: <https://github.blog/news-insights/company-news/welcome-home-agents/>
